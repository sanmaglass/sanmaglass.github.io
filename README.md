# Portafolio — Luis San Martín

Sitio estático publicado en https://sanmaglass.github.io

Visión computacional y sistemas de datos en producción: conteo y clasificación en
línea de empaque, integración de punto de venta sin API y reportería automatizada.

## Estructura

- index.html — el sitio completo (HTML + CSS + JS inline, sin dependencias externas)
- ssets/fonts/ — Anton (titulares), Geist y Geist Mono (texto y datos)
- ssets/media/ — video de la línea de empaque, conteo de larvas, retrato

Sin framework, sin build, sin dependencias. Se sirve tal cual.

## Origen del material

El video y las imágenes de detección son salidas reales de los sistemas descritos.
El código de los proyectos es privado por tratarse de sistemas en operación de clientes.
